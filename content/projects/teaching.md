## What it is

The lab's teaching side: the **Formulas and Vehicles** course, where students program
underwater robots, and the Python onramp that gets them ready.

## The pieces

- **`fav_docs`** — the course documentation site
  ([hippocampusrobotics.github.io/fav_docs](https://hippocampusrobotics.github.io/fav_docs/)):
  installation, assignments, the robot, tutorials.
- **`python-onramp`** — the Python introduction used before the course.

## Where it stands

Active each course cycle. This site's Setup section and the course docs overlap on
purpose: the course docs teach, Setup operates. When they disagree on a lab procedure,
Setup here is the one the lab maintains.
