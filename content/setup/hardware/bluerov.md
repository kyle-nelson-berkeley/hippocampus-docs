# BlueROV

- The old BlueROV. We use it mainly for the SEMS/FAV class. It's vehicle name is `bluerov-01`.

- The newer BlueROV. This one is used for the UVMS setup and has the Alpha arm mounted to it. It's vehicle name is `bluerov-02`.
